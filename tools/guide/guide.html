앱 주소 (폰 카메라로 왼쪽 QR을 찍어도 열려요)

joyunho.github.io/cafedemung

  • 가입·코드·비밀번호 없음. 주소만 열면 누구 폰이든 같은 재고 화면이 나와요.
  • 누가 숫자를 고치든 모든 폰에 몇 초 안에 똑같이 보여요.
  • 인터넷이 잠깐 끊겨도 적을 수 있고, 다시 연결되면 알아서 보내요.

1처음 열기

  1. 주소 열기위의 QR을 찍거나, 카톡으로 받은 링크를 눌러요. 다른 사람에게 줄 때도 이 주소만 보내면 돼요(설정의 주소 보내기).
  2. 홈 화면에 추가 (앱처럼 쓰기) 아이폰: Safari 아래 공유 버튼(네모에 화살표) → 홈 화면에 추가
    안드로이드: 크롬 오른쪽 위 ⋮ → 앱 설치 또는 홈 화면에 추가
    다음부터는 홈 화면의 아이콘으로 열면 돼요.
  3. 이름 넣기 (선택)초록 칸에 이름을 적고 저장. 숫자 옆에 누가 고쳤는지 이름이 남아요. 나중에 설정(톱니바퀴)에서 바꿀 수 있어요.
  4. 노란 안내 "가게 숫자를 받아오는 중"새 폰은 다른 폰에서 실제 숫자를 받아올 때까지 숫자를 고칠 수 없어요. 보통 몇 초면 사라져요. 오래 걸리면 사장님 폰에서 앱을 한 번 열어 주세요.

"처음 숫자로 시작"은 누르지 마세요

가게를 완전히 새로 시작할 때만 쓰는 버튼이에요. 받아오기 전에 누르고 숫자를 고치면 시트의 옛 숫자가 섞일 수 있어요.

2숫자 적기

  • 위의 탭으로 구역을 골라요: 음료 · 음료 재료 · 과일·케이크 · 포장·소모품
  • 안뜯은거 = 아직 안 뜯은 새 것, 뜯은거 = 뜯어서 쓰고 있는 것
  • − +를 누르거나, 가운데 숫자 칸을 눌러 직접 적어요. 비우면 "모름(미기입)"이에요.
  • 적는 순간 저장되고, 몇 초 안에 모든 폰에 똑같이 보여요. 저장 버튼은 없어요.
  • 이름 아래 "보내는 중"이 붙어 있으면 아직 다른 폰에 안 간 거예요. 인터넷이 연결되면 알아서 보내요.

잘못 눌렀을 때: 되돌리기

숫자를 바꾸면 화면에 "탄산수 안뜯은거 96 → 94 · 되돌리기"가 4초쯤 떠요. 되돌리기를 누르면 바로 전 숫자로 돌아가요.

  • 1분 안에 연달아 누른 건 한 줄로 묶여서 한 번에 돌아가요.
  • 놓쳤으면 항목 이름을 눌러 최근 기록에서 되돌릴 수 있어요(3쪽).
  • 그 사이 다른 사람이 같은 칸을 또 바꿨으면, 그 사람 숫자를 지우지 않도록 되돌리지 않아요.

3한눈에 · 주문 목록 · PDF

  • 위의 한눈에를 누르면 맨 위에 주문 목록(없음·마지막·부족)이 모여요.
  • 복사 → 카톡에 붙여넣기. 구역·분류까지 같이 들어가요.
  • PDF → 주문 목록만 또는 주문 목록 + 전체 재고표 → 공유하기(카톡 등)나 파일로 저장. 사진은 빼고 항목·숫자·상태·메모·마지막 수정만 표로 담겨요. 처음 한 번은 인터넷이 필요해요.
  • 그 아래 최근 변경(7일): 누가 언제 무엇을 바꿨는지. 누르면 그 항목으로 가요.
  • 맨 아래 구역별 표의 수정 칸에 날짜와 이름. 줄을 누르면 입력 화면의 그 항목으로 가요.
  • 입력 화면의 부족만은 없음·마지막·부족만 모아 보여 주고, 검색으로 이름을 찾을 수 있어요.

4항목 고치기 · 추가 · 사진

  • 항목 이름(›)을 누르면 편집 화면이 열려요: 이름 · 구역 · 분류 · 메모 · 최소 수량 · 사진 주소. 저장을 눌러야 바뀌어요.
  • 아래 최근 기록: 누가 · 언제 · 몇에서 몇으로 바꿨는지 (항목마다 최근 8개). 안뜯은거·뜯은거마다 가장 최근 줄에 되돌리기가 있어요.
  • 새 항목은 위의 +, 지우기는 편집 화면 왼쪽 아래 삭제. 모든 폰에 같이 반영돼요.

사진 바꾸기

기본 사진은 비슷한 제품의 예시 사진이에요. 가게 제품과 다르면:

  1. 항목 이름 → 구글 이미지에서 찾기
  2. 맞는 사진을 길게 눌러 이미지 주소 복사
  3. 편집 화면의 사진 주소 칸에 붙여넣고 저장 → 모든 폰에 같이 바뀌어요

사진을 누르면 크게 볼 수 있어요. 사진 주소를 비우면 기본 사진으로 돌아가요.

5사장님 폰 알림 (ntfy 앱)

누가 숫자를 바꿔서 없음 마지막 부족이 되면, ntfy(무료 알림 앱)를 깐 폰으로 푸시 알림이 와요. 처음 한 번만 설정하면 돼요.

안드로이드

  1. Play 스토어에서 ntfy 설치
  2. 재고 앱 → 설정(톱니바퀴) → 알림 받기 (안드로이드) → ntfy 앱에서 구독

아이폰

  1. App Store에서 ntfy 설치 → 알림 허용
  2. ntfy 앱 → + → 주제(Topic)에 아래 이름을 그대로 적고 Subscribe (서버는 바꾸지 않아요)
    cdm-alert-5a38130f323e1e76331c
    설정의 주제 이름 복사로 복사해서 붙여넣어도 돼요.

마지막으로 설정의 테스트 알림 보내기로 알림이 오는지 확인해요.

  • 알림은 숫자를 바꾼 폰에서 6초쯤 뒤에 한 번만 가요. 그 사이 되돌리면 안 가요.
  • 같은 항목이 같은 상태면 10분 안에 또 보내지 않아요.
  • 알림을 누르면 재고 앱이 열려요(아이폰은 Safari로 열려요).
  • 이 폰에서 알림을 보내지 않으려면 설정의 체크를 끄면 돼요.

6이럴 땐 이렇게

노란 "받아오는 중"이 안 없어져요
다른 폰(사장님 폰 등)에서 앱을 한 번 열어 주세요. 그래도 그대로면 설정 → 지금 받아오기.
다른 폰 숫자가 안 보여요
오른쪽 위가 동기화 중인지 봐요. 오프라인 / 다시 연결 중이면 인터넷을 확인하고 앱을 닫았다 다시 열어요.
잘못 고쳤어요
바로 뜨는 되돌리기, 또는 항목 이름 → 최근 기록 → 되돌리기.
새 직원 · 폰을 바꿨어요
주소만 열면 끝이에요. 다른 폰이 켜져 있으면 숫자를 알아서 받아와요.
구글 시트에 옮기고 싶어요
설정 → 표로 복사 → 시트에 붙여넣기. 백업 파일 저장으로 파일로도 남길 수 있어요.
종이로 뽑고 싶어요
한눈에 → 주문 목록 PDF, 또는 설정 → 재고표 PDF.

꼭 알아 두세요

  • 코드 없이 쓰도록 만들어서, 주소를 아는 사람은 누구나 보고 고칠 수 있어요. 주소는 가게 사람끼리만 나눠 주세요.
  • 설정의 시트 값으로 초기화는 모든 폰의 숫자를 예전 시트의 처음 숫자로 되돌려요. 실수로 누르지 않게 조심하세요.
