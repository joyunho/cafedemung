# 카페드명 재고체크

사장님과 직원이 **같은 숫자**를 보며 재고를 적는 폰 앱입니다. 홈 화면에 설치해서 앱처럼 열고, −/+ 버튼으로 숫자를 바꿉니다.
가입도, 코드 입력도 없습니다. **주소만 열면 누구 폰이든 같은 재고 화면**이 나오고, 누가 숫자를 바꾸든 모두에게 같이 반영됩니다.

**앱 주소**: https://joyunho.github.io/cafedemung/

## 쓰는 법

1. 위 주소를 폰에서 엽니다. 기존 재고 시트에서 옮겨온 101개 항목이 바로 보입니다.
2. 같이 볼 사람에게 주소만 보내면 됩니다(설정의 **링크 보내기**). 코드나 계정은 필요 없습니다.
3. 이름은 선택입니다. 위에 뜨는 "이름 넣기"에 적으면 누가 고쳤는지 표시됩니다.
   - 처음 여는 폰은 다른 폰의 숫자를 받아올 때까지 숫자를 고칠 수 없습니다(시트의 처음 숫자로 실제 숫자를 덮어쓰지 않도록). 보통 몇 초 안에 받아오고, 다른 폰이 모두 꺼져 있으면 누군가 앱을 열 때 받아옵니다. 완전히 새로 시작하는 가게라면 안내의 **처음 숫자로 시작**을 누르세요.
4. 홈 화면에 추가하면 앱처럼 열립니다. iPhone은 Safari 공유 버튼 → "홈 화면에 추가", Android는 "설치" 안내를 누릅니다.

### 화면
- **입력**: 구역 탭(음료 / 음료 재료 / 과일·케이크 / 포장·소모품)별로 분류마다 항목이 나오고, 안뜯은거 / 뜯은거를 −/+ 또는 직접 입력으로 바꿉니다. 항목 이름을 누르면 이름·구역·분류·메모·최소 수량을 바꾸거나 삭제할 수 있고, + 버튼으로 추가합니다.
- **한눈에**: 맨 위에 **주문 목록**(없음·마지막·부족 항목)이 모이고 "복사"로 바로 카톡에 붙여넣을 수 있습니다. 아래로 구역별 표가 이어지고, 행을 누르면 그 항목의 입력 화면으로 갑니다.
- **부족만** 버튼: 없음(안뜯은거 0) · 마지막(뜯은 것만 남음) · 부족(최소 수량 미만)만 모아 봅니다.
- 요약 줄에 항목 수, 없음/마지막/부족 수, 최근 수정, 연결된 폰이 보입니다.

### 변경 기록 · 되돌리기
- 숫자를 바꾸면 아래에 "탄산수 안뜯은거 120 → 117 · **되돌리기**"가 잠깐 뜹니다. 1분 안에 연달아 누른 건 한 줄로 묶이고, 되돌리기도 한꺼번에 됩니다.
- 항목 이름을 누르면 편집 화면 아래에 **최근 기록**(누가·언제·몇에서 몇으로)이 있고, 줄마다 되돌리기가 있습니다.
- "한눈에" 화면에 **최근 변경**(최근 7일)이 모여 보이고, 누르면 그 항목으로 갑니다.
- 기록은 항목마다 최근 8개씩 폰끼리 같이 주고받습니다. 두 폰이 동시에 고쳐도 둘 다 남습니다.

### 사장님 폰 알림
- 누가 숫자를 바꿔서 **없음·마지막·부족**이 되면 ntfy 앱을 깐 폰으로 푸시 알림이 갑니다(누르면 앱이 열림).
- 설정 → 알림: ntfy 앱 설치 후 안드로이드는 **알림 받기**, 아이폰은 앱에서 + 를 눌러 **주제 이름**을 붙여넣으면 됩니다. **테스트 알림 보내기**로 확인하세요.
- 알림은 숫자를 바꾼 폰에서 한 번만 보냅니다. 폰마다 "이 폰에서 바꾼 숫자가 부족해지면 알림 보내기"를 끌 수 있습니다.

### 배치 정리 (2026년 10월)
- 사람 이름으로 된 임시 목록('윤영 정리', '윤호 정리')을 종류별 탭으로 나눴습니다.
- '윤영 정리'는 **음료**(탄산·스파클링, 우유·주스, 유기농, 뽀로로)와 **음료 재료**(시럽, 소스, 파우더, 티백, 아이스티, 스무디·베이스, 토핑·잼)로 나눴습니다.
- '윤호 정리'는 냉동과일·과일청/베이스·케이크·아이스크림은 **과일·케이크** 탭으로 옮겼습니다. 쉬폰 비닐·받침, OPP 봉투, 냅킨은 포장·소모품에 이미 있던 같은 물건과 합치고 숫자를 더했습니다.
- 이미 쓰던 폰도 새 버전을 처음 열 때 한 번 자동으로 정리되고, 연결된 폰끼리 같은 결과가 됩니다.
- 주문 목록 복사에 분류도 함께 나옵니다 (예: `[과일·케이크 · 케이크]`).

### 제품 사진
- 모든 항목 왼쪽에 사진이 있고, 누르면 크게 보입니다. "한눈에" 표와 주문 목록에도 작은 사진이 나옵니다.
- 기본 사진은 **비슷한 제품의 예시 사진**입니다. 무료 라이선스 사진(Open Food Facts, 위키미디어 커먼즈)만 쓰며, 출처는 `img/CREDITS.md`와 사진 크게 보기 화면에 있습니다.
- 가게 제품과 다르면 항목 이름을 눌러 **사진 주소**에 이미지 주소를 붙여넣으면 됩니다. "구글 이미지에서 찾기" 버튼으로 검색한 뒤, 사진을 길게 눌러 "이미지 주소 복사"를 하면 됩니다. 바꾼 사진은 연결된 폰에도 같이 바뀝니다.
- 기본 사진 자체를 바꾸려면 `img/sources.json`에서 그 항목의 검색어나 출처를 고치세요. GitHub Actions(Fetch product images)가 사진을 다시 받아 320px 썸네일로 줄여 `img/items/`에 넣고 다시 게시합니다.

### 설정 시트(톱니바퀴)
- 앱 주소 보기, 링크 보내기/복사, 지금 받아오기
- 이름 바꾸기 (공용 코드를 끄면 가게 코드 보기·바꾸기)
- 표로 복사(스프레드시트에 붙여넣기), 백업 파일 저장/불러오기, 시트 값으로 초기화

## 동기화가 되는 원리

- 모든 데이터는 폰 안(브라우저 저장소)에 있습니다. 인터넷이 없어도 입력은 되고, 연결되면 보냅니다.
- 변경 내용은 ntfy.sh(가입 없는 공개 메시지 중계)로 보냅니다. `config.js`의 **공용 가게 코드**(`SHARED_CODE`)로 만든 채널을 모두 함께 씁니다.
  - 코드가 `config.js`에 공개되어 있으므로 **주소를 아는 사람은 누구나 보고 고칠 수 있습니다** (일부러 그렇게 함).
  - 예전처럼 폰마다 코드를 넣어 연결하려면 `SHARED_CODE`를 `""`로 비우면 됩니다. 그때는 처음 설정·연결 링크 방식으로 돌아갑니다.
  - 예전 코드를 쓰던 폰은 새 버전을 열 때 들고 있던 숫자를 공용 채널로 그대로 가져옵니다.
- 두 폰이 함께 켜져 있으면 몇 초 안에 반영됩니다. 꺼져 있던 폰은 다음에 열 때 지난 12시간치를 받아오고, 그보다 오래된 변경은 3일 동안 예약 전송되는 전체 사본으로 따라잡습니다.
- 같은 항목을 두 폰이 동시에 고치면 **나중에 입력한 값**이 남습니다. 항목별로 안뜯은거/뜯은거/이름·메모가 따로 비교되므로 서로 다른 칸을 고친 건 둘 다 살아남습니다.
- 3일 넘게 어느 폰도 열지 않았다면 설정의 **지금 받아오기**를 누르면 상대 폰이 켜졌을 때 전체를 다시 받습니다. 백업 파일로 직접 옮길 수도 있습니다.

## 저장소 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 앱 전체 (화면, 저장, 동기화) |
| `config.js` | 중계 서버 주소, 공용 가게 코드 |
| `sw.js`, `manifest.webmanifest`, `icons/` | 홈 화면 설치(PWA)용 |
| `404.html` | 주소 뒤에 글자가 잘못 붙어 열려도 앱 첫 화면으로 보냄 (연결 코드 유지) |
| `img/sources.json` | 항목별 사진 출처와 검색어 |
| `img/items/`, `img/manifest.json`, `img/CREDITS.md` | 자동으로 만들어지는 사진 썸네일, 목록, 출처 표 |
| `tools/fetch_images.py`, `.github/workflows/images.yml` | 사진을 받아 썸네일로 줄이는 스크립트와 자동 실행 |
| `tests/` | 가짜 중계 서버와 크롬으로 전체 흐름을 돌려보는 검사 (`node tests/smoke.mjs`) |
| `.github/workflows/test.yml` | 올릴 때마다 위 검사를 자동 실행 |
| `.github/workflows/deploy.yml` | main에 올리면 앱 파일을 gh-pages 브랜치로 게시 |

앱 파일을 고친 뒤 main에 올리면 자동으로 다시 게시됩니다.
