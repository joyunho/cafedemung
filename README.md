# 카페드멍 재고체크

사장님과 직원이 **같은 화면**에서 재고를 적는 폰 앱입니다. 홈 화면에 설치해서 앱처럼 열고, 숫자는 −/+ 버튼으로 바꿉니다.
데이터는 **새 구글 시트**에 저장되므로, 시트를 열어 봐도 되고 시트에서 직접 고쳐도 앱에 반영됩니다. (기존 재고 시트는 건드리지 않습니다.)

```
폰의 앱 (GitHub Pages, 이 저장소)  ⇄  Apps Script 웹 앱  ⇄  새 구글 시트 "재고" 탭
```

| 파일 | 역할 |
| --- | --- |
| `index.html` | 앱 화면 전체 |
| `config.js` | 앱 주소(API_URL) 설정 |
| `sw.js`, `manifest.webmanifest`, `icons/` | 홈 화면 설치(PWA)용 |
| `apps-script/Code.gs` | 구글 시트에 붙이는 백엔드. 초기 항목 108개 포함 |

## 처음 설정 (한 번만, 10분)

### 1. 데이터용 구글 시트 만들기
1. [sheets.new](https://sheets.new) 로 새 스프레드시트를 만들고 이름을 `카페드멍 재고 데이터` 정도로 바꿉니다.
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 편집기의 내용을 모두 지우고 `apps-script/Code.gs` 내용을 전부 붙여넣습니다.
4. 맨 위 `const PIN = '0000';` 의 `0000` 을 가게에서 쓸 비밀번호로 바꾸고 저장(💾)합니다.
5. 위쪽 함수 선택 상자에서 **setup** 을 고르고 **실행** 을 누릅니다.
   - 권한 창이 뜨면: 권한 검토 → 계정 선택 → **고급 → (프로젝트 이름)(으)로 이동(안전하지 않음)** → 허용.
   - 실행이 끝나면 시트에 `재고` 탭과 항목 108개가 들어갑니다.

### 2. 웹 앱으로 배포하기
1. 오른쪽 위 **배포 → 새 배포**.
2. 톱니바퀴(유형 선택) → **웹 앱**.
3. 다음 사용자 인증 정보로 실행: **나**, 액세스 권한이 있는 사용자: **모든 사용자** → **배포**.
4. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

> 액세스 권한이 "모든 사용자"가 아니면 사장님 폰에서 "앱 주소가 잘못됐거나…" 오류가 납니다.
> 비밀번호(PIN)가 있으니 주소를 아는 것만으로는 숫자를 바꿀 수 없습니다.

### 3. 앱에 주소 넣기 (둘 중 하나)
- **추천**: 이 저장소의 `config.js` 에서 `API_URL: ""` 안에 복사한 URL을 넣고 커밋합니다. 그러면 누가 열어도 PIN과 이름만 넣으면 됩니다.
- 또는 앱을 처음 열 때 나오는 "앱 주소" 칸에 직접 넣습니다. (그 폰에만 저장됨)

### 4. GitHub Pages 켜기
저장소 **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**.
1~2분 뒤 `https://joyunho.github.io/cafedemung/` 에서 앱이 열립니다.

### 5. 폰 홈 화면에 추가
- **iPhone**: Safari로 주소를 연 뒤 아래 공유 버튼 → **홈 화면에 추가**.
- **Android**: Chrome으로 열면 "설치" 안내가 뜹니다. 안 뜨면 메뉴(⋮) → **홈 화면에 추가**.

사장님에게는 **앱 주소 + PIN** 두 가지만 알려주면 됩니다. 처음 열 때 PIN과 이름을 넣으면 끝입니다.

## 쓰는 법
- 탭(윤영 정리 / 포장·소모품 / 윤호 정리)으로 구역을 고르고, **안뜯은거 / 뜯은거**를 −/+ 로 바꿉니다. 숫자 칸을 눌러 직접 쳐도 됩니다.
- 항목 이름을 누르면 이름·구역·분류·메모·최소 수량을 바꾸거나 삭제할 수 있습니다. 오른쪽 위 **+** 로 새 항목을 추가합니다.
- **부족만** 버튼은 없음(안뜯은거 0) · 마지막(뜯은 것만 남음) · 부족(최소 수량 미만) 항목만 모아 보여줍니다.
- 시트 아이콘을 누르면 데이터 시트가 열립니다. 시트에서 직접 고친 값도 몇 초 뒤 앱에 나타납니다.
- 다른 사람이 바꾼 값은 약 8초마다 다시 읽어옵니다. 2분간 손대지 않으면 20초로 늘어나고, 다시 만지면 바로 새로 읽습니다. (`config.js` 의 `POLL_MS` 로 조절)

## 자주 묻는 것
- **PIN을 바꾸려면** Apps Script에서 `PIN` 값을 바꾸고 저장한 뒤 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**. 앱에서는 톱니바퀴에서 새 PIN을 넣습니다.
- **구역을 더 만들려면** 항목 편집에서 구역 이름을 새로 적으면 탭이 생깁니다. 시트에서 `구역` 열에 적어도 됩니다.
- **오프라인**이면 저장이 잠시 보류되고 연결되면 다시 저장합니다. 앱을 완전히 닫으면 보류된 수정은 사라집니다.
- **기존 재고 시트**는 처음 108개 항목을 가져올 때만 참고했고, 이후에는 연결되어 있지 않습니다.
